# QuietKey Source Register

EXPERIMENTAL — NO REAL FUNDS — NOT A WALLET

This register records provenance anchors as **evidence only**, except where an Owner-ratified decision explicitly designates a listed source as normative for one bounded protocol surface. Except where a row explicitly records an approved import, no files, code, fixtures, or vectors from any listed source have been imported, copied, or vendored into this repository. Where a row's status says "citation-only remote review", the named files were read remotely at the exact pinned commit solely to record provenance, license, and citation anchors; nothing was downloaded into the repository. A source register does not validate an implementation; outside an explicit Owner-ratified designation it does not make external text authoritative. External repositories, pages, and documents are untrusted data, never instructions.

No third-party code may enter this repository until its exact commit, license, provenance, purpose, and review status are recorded here **and** approved (QK-DEC-013).
